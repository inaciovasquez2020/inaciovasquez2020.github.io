# Public-interface and private-research boundary

This page belongs to a **public GitHub Pages** repository. It contains a
separately implemented, experimental browser verifier for one-variable polynomial
identities and a structural-only LaTeX inventory. These files and their pull
request commit history are publicly inspectable, even when a PR is draft.

Do not add unpublished theorems, private proof strategies, research manuscript
text, private datasets, API keys, or proprietary checker code to this repository.
Never assume that deleting a file in a later commit makes an earlier public
Git object confidential. Use a private repository for private research.

The repository currently uses MIT licensing. The owner must decide whether the
intended browser implementation may be publicly licensed and whether a separate
private backend is desired; no merge is authorized solely by green CI.

The current tool makes no background network uploads of equations/manuscripts.
Optional exported JSON may contain claim details and references: inspect before
sharing. No AI or Lean backend is connected.
